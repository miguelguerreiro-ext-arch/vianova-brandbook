# Logos

The Vianova mark as it stands in the Figma component `Vianova Brand logo` (119:1240). Place a file with `<img>`; never redraw or recolour it.

- `vianova-logo.svg` — Full lockup, original colours. For `surface-page` and other light grounds. Cover at 38pt tall, page header at 16.772pt.
- `vianova-logo-dark.svg` — Full lockup, colour symbol with a white wordmark. For `accent-default` and dark photographs.
- `vianova-logo-white.svg` — Full lockup, all white. For a ground where the colour symbol would clash.
- `vianova-logo-black.svg` — Full lockup, one ink, black. For one-colour print.
- `vianova-symbol.svg` — Symbol only, original colours. Small or repeating placements; never in place of the lockup on a cover.
- `vianova-symbol-white.svg` — Symbol only, white.
- `vianova-symbol-black.svg` — Symbol only, black.

The white and black files are fixed inks, not `currentColor`; pick the file, do not restyle it. The dashed artboard guide that the product repository's copies carry has been removed from these.
