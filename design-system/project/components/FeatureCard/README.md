# Feature card

Capability tile: a 5pt dot, a title and one short paragraph, used in pairs across the measure. Figma: `VN-Minimal / Feature card` 54:57.

```html
<div class="vn-features">
  <div class="vn-feature"><div class="vn-ft">Card title goes here</div><p class="vn-fd">Two or three sentences.</p></div>
  <div class="vn-feature">…</div>
</div>
```

Title is `heading-card-title`, description `table-cell` in `text-secondary`; `surface-raised`, hairline border, radius 4pt, padding 10 / 12 / 11pt. The dot is `secondary-default`: teal marks what already exists, which is what a capability tile claims. The master defines no other dot colour, so do not recolour it per card. Keep an even number of cards and titles to one line.
