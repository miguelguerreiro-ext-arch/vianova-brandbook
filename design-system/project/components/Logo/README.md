# Logo

The Vianova mark: full lockup or symbol, each in original, white text, white or black. Figma: `Vianova Brand logo` 119:1240.

Use the full lockup wherever there is room and the ground is light. The symbol is for small or repeating placements, never as a substitute on a cover. Place a file from the Logos asset group with `<img>`; never redraw or recolour the mark, and never rebuild its gradient in CSS.

| Where | File | Height |
|---|---|---|
| Cover, at x 54 y 56 | `vianova-logo.svg` | 38pt |
| Page header, left | `vianova-logo.svg` | 16.772pt |
| On `accent-default` or a photo | `vianova-logo-dark.svg` (colour symbol, white wordmark) or `vianova-logo-white.svg` | as above |
| One-ink print | `vianova-logo-black.svg` | as above |

The logo's own gradient is a different object from the five-stop brand gradient on the bar. Both are correct; do not swap one for the other.
