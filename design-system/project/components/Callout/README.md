# Callout

One emphasised line, set apart on the raised surface. Figma: `VN-Minimal / Callout` 54:90.

```html
<div class="vn-callout">A callout carries one emphasised line: a pointer, a caveat, or the claim the section rests on.</div>
```

`body-strong` in `text-heading` on `surface-raised`, 0.75pt `border-default`, radius 4pt, padding 11 / 14 / 12pt. One sentence. No label, no icon, no left accent rule. A paragraph that needs explaining is a worked example (proposal), not a callout.
