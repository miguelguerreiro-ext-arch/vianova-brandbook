# Subsection header

Number in `accent-default`, title in `text-heading`, both `heading-subsection`. Figma: `VN-Minimal / Subsection header` 54:46.

```html
<h2 class="vn-sub"><span class="vn-no">1.1</span>Subsection title</h2>
```

The number is the only accent colour in running copy. Two levels of numbering are the limit; below that use a run-in head. Known differences: the master sets an 8pt gap between number and title and the kit sets 6pt; the Figma description calls the number teal, but it is bound to `accent/default`, navy.
